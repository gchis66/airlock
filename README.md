# Airlock: Try to Break My Agent

A customer support agent for a fake outdoor gear store, built to be attacked. The model proposes actions. Plain Python code decides whether they run. A red-team eval suite in CI checks that on every push.

**Status:** under construction (Stage 0 of 8).

Built with Python, LangGraph, Amazon Bedrock (Claude Haiku 4.5, Guardrails, Titan embeddings), FastAPI, AWS Lambda and Terraform.
